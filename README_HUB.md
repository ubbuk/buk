# 1С өгөгдлийн hub: dashboard-д зориулсан заавар

Өмнө нь dashboard 1С-ийн `/hs/dash/*` руу шууд хандаж байсан. Одоо **ERP (Hangamj)** 1С-ээс 15 минут тутамд өгөгдлөө татаж
өөрийн DB-д хадгална. Dashboard **ERP-ийн хаягаас** уншина. 1С унтарсан үед ч сүүлийн өгөгдөл хэвээр байна.

```
1С ──(15 мин тутам)──► ERP (Postgres) ──► /api/v1/onec/* ──► Dashboard
```

## Шинэ хаяг

Суурь хаяг: `https://<ERP-ийн-хаяг>/api/v1/onec` (бодит хаягийг ERP-ийн хариуцагчаас авна).

| Өмнөх (1С)               | Одоо (ERP)                                         | Параметр                                  |
| ------------------------ | -------------------------------------------------- | ----------------------------------------- |
| `/hs/dash/stock`         | `/api/v1/onec/stock`                               | `?asof=YYYY-MM-DD`                        |
| `/hs/dash/receivables`   | `/api/v1/onec/receivables`                         | `?asof=YYYY-MM-DD`                        |
| `/hs/dash/sales`         | `/api/v1/onec/sales`                               | `?from=YYYY-MM-DD&to=YYYY-MM-DD` (заавал) |
| `/hs/dash/cash`          | `/api/v1/onec/cash`                                | `?from=YYYY-MM-DD&to=YYYY-MM-DD` (заавал) |
| `/hs/dash/pl`            | `/api/v1/onec/pl`                                  | `?from=YYYY-MM-DD&to=YYYY-MM-DD` (заавал) |

Зөвхөн `GET`. Мөрийн талбарын нэр, төрөл 1С-ийнхтэй **яг адилхан** (өдөр нь `"2026-10-01"` string, дүн/тоо нь number).

## Хариулт

```json
{
  "asof": "2026-11-12",
  "rows": [ { "...": "1С-ийн мөртэй ижил" } ],
  "count": 123,
  "generated": "2026-11-12T10:15:03",
  "synced_at": "2026-11-12T02:07:41.512Z"
}
```

- `rows`, `count`, `generated`: 1С-ийнхтэй ижил (`generated` нь Улаанбаатарын цаг).
- **`synced_at`** (шинэ): ERP энэ төрлийн өгөгдлийг 1С-ээс хамгийн сүүлд АМЖИЛТТАЙ татсан цаг (UTC, ISO). Хэзээ ч амжилттай
  болоогүй бол `null`. Өгөгдөл хэр шинэ болохыг энэ утгаас шалгаж, хуучирсан бол dashboard дээр «сүүлд шинэчилсэн: …» гэж
  харуулахыг зөвлөе. 15 минут хүртэл хоцрох нь хэвийн, 1С унтарвал үүнээс удаан байж болно.
- **`asof`** (зөвхөн `stock`, `receivables`): бодит агшин зургийн огноо. Хүссэн огнооны агшин зураг байхгүй бол ERP **хамгийн
  сүүлийн** агшин зургийг буцааж, энд бодит огноог бичнэ. `asof` өгөөгүй бол мөн хамгийн сүүлийнхийг өгнө. Огт өгөгдөл
  байхгүй бол `"asof": null`, `rows: []`.
- `Cache-Control: no-store`: хариуг кэшлэхгүй.

## Анхаарах зүйлс (1С-ээс ялгаатай)

- **`pl`** нь ERP-д **сараар** хадгалагддаг. `from..to`-той огтлолцох бүх сарыг бүтнээр нь буцаана (хагас сар асуувал тэр
  сарын бүтэн P&L ирнэ). Сараар нь асуухыг зөвлөе.
- `sales`, `cash`, `pl`: `from`, `to` хоёулаа заавал, `from <= to`, хугацаа **400 хоногоос хэтрэхгүй**.
- Хариултын хэмжээ: ERP нь Vercel дээр ажилладаг тул нэг хариулт ~4.5 MB-аас хэтрэхгүй байх ёстой. Том хугацааг (жишээ нь
  жилийн борлуулалт) **сараар нь хуваан** авна.
- 1С-ийн «кирилл нэр, UTF-8 Basic auth»-ыг ашиглахаа больсон.

## Нэвтрэлт

Хүсэлт бүрт `Authorization: Bearer <түлхүүр>` header явуулна. Түлхүүрийг ERP-ийн хариуцагч тусад нь (мессенжер/нууц
сангаар, repo-оор БИШ) өгнө.

- Түлхүүрийг dashboard-ийн **нууц хувьсагчид** (жишээ нь `ONEC_HUB_API_KEY`) хадгална. Кодонд, git-д, лог-д бүү бич.
- Түлхүүр байхгүй, буруу бол `401 {"error":"Unauthorized"}`. Огноо буруу бол `400`
  (`{"error":"asof must be yyyy-MM-dd"}` эсвэл `{"error":"from and to must be yyyy-MM-dd"}`). `GET`-ээс бусад арга `405`.
- Түлхүүр алдагдсан гэж сэжиглэвэл ERP-ийн хариуцагчид хэлнэ үү: түлхүүрийг солиход л хангалттай (хуучин нь шууд хүчингүй болно).

```bash
curl -s -H "Authorization: Bearer $ONEC_HUB_API_KEY" \
  "https://<ERP-ийн-хаяг>/api/v1/onec/cash?from=2026-11-01&to=2026-11-30"
```

## `export_1c.py` дээр юуг солих

Таны файлыг бид харж, өөрчлөөгүй. Доорх нь солих зүйлсийн жагсаалт:

1. **Хаяг:** `ONEC_BASE_URL` (1С-ийн `http://…/<infobase>`)-ийг ERP-ийн хаяг болгоно. Замын `"/hs/dash/<нэр>"`-ыг
   `"/api/v1/onec/<нэр>"` болгоно (`<нэр>` = `stock | cash | sales | pl | receivables`). Параметрийн нэр хэвээр.
2. **Нэвтрэлт:** Basic auth (1С-ийн нэр/нууц үг)-ийг Bearer болгоно:

   ```python
   # өмнө
   r = requests.get(url, params=params, auth=(ONEC_USER, ONEC_PASSWORD), timeout=300)

   # одоо
   r = requests.get(url, params=params,
                    headers={"Authorization": f"Bearer {ONEC_HUB_API_KEY}"}, timeout=60)
   ```

3. **Нууц хувьсагч:** `ONEC_USER`, `ONEC_PASSWORD`-ийг хасаж, `ONEC_HUB_API_KEY`-ийг нэмнэ (1С-ийн нууц үг танд хэрэггүй болно).
4. **Хариулт задлах:** `data["rows"]` хэвээр. Хүсвэл `data["synced_at"]`, `data["asof"]`-ийг ашиглана (нэмэлт талбар, одоогийн
   кодыг эвдэхгүй).
5. **Timeout:** 1С удаан (30 сек+) байсан бол одоо DB-ээс уншдаг тул 60 секунд хангалттай.
6. **Алдаа:** `401` (түлхүүр буруу), `400` (параметр буруу) нь дахин оролдоод засагдахгүй. Дахин оролдлогыг зөвхөн сүлжээний
   алдаа, `5xx`-д хийнэ.
7. **Том хугацаа:** `sales`, `cash`-ийг сараар нь хуваан татна (дээрх «Анхаарах зүйлс»).
