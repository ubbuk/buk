# 1С хөтчийн монгол нэр томьёо

> Энэ баримтыг `lib/onec-odata/labels-mn.ts`-ээс автоматаар үүсгэсэн (`npm run onec:labels-doc`). **Ерөнхий нягтлан бодогч шалгана.**
> Засвар хийхдээ баруун баганын монгол нэрийг өөрчлөөд хөгжүүлэгчид өгнө: хөгжүүлэгч `labels-mn.ts`-д тусгаж, энэ баримтыг дахин үүсгэнэ.

Орчуулга нь зөвхөн дэлгэц дээрх нэрэнд нөлөөлнө. Эрхийн шалгалт (хориотой, цалин, няравт нээлттэй жагсаалт) 1С-ийн жинхэнэ нэрээр явагдана.
Орчуулгагүй объект, баганыг 1С-ийн жинхэнэ нэрээр нь харуулна. Дэлгэц дээр монгол нэр том, 1С-ийн нэр доор нь жижиг саарал үсгээр харагдана.

Объектын түлхүүр нь `Catalog_Номенклатура` гэх мэт нэрийн `_`-ийн дараах хэсэг (`Номенклатура`). Ижил нэртэй өөр төрлийн объект зөрчилдвөл бүтэн нэрийг бичнэ.

## Техникийн объект

Дараах объектууд «Техникийн» гэсэн тусдаа, анхдагчаар хаалттай бүлэгт орно (эрхэд нөлөөлөхгүй, зөвхөн харагдах байдал):

- нэр нь `Constant_` эсвэл `ExchangePlan_`-аар эхэлсэн
- нэр нь `_RecordType`-аар төгссөн
- нэрэнд `ДополнительныеРеквизиты`, `ДополнительныеСведения`, `ПрисоединенныеФайлы`, `ВерсииФайлов` агуулагдсан
